# 使用说明（v0.6.0）

面向第一次打开的人。三步能用起来，其余按需再看。

---

## 一、三步开始

1. **开始听**：首页音源条上点「开始」。第一次会让你确认一段隐私说明——里面写明「记录会保存在这台电脑上」「不等于加密」。
2. **看字幕**：对方说话后，上面是外语原文、下面是你看得懂的译文，再下面一行是读音提示（可以关掉）。
3. **照着说**：点字幕右边的小喇叭可以先听一遍；点提示里的任意一段可以定位到对应那个词。

> 默认是**真实采集**（抓电脑正在播放的声音）。左下角出现橙色「演示模式：听不到电脑里的声音」说明你现在在演示模式，点一下就能切到真实监听。

---

## 二、先确认「它真的在听」

音源条一行给三件事：**设备名**、**用途**、**状态**。

- 状态「正在监听」+ 那条 2px 电平线在动 = 收到声音了。
- 状态「正在监听，但没有听到任何声音」= 设备开了，但一片安静。按顺序查：视频真的在播？系统音量不是 0？播放软件的输出是**系统默认扬声器**？
- 一直不对就点「一键诊断」，它只显示有问题的项。

---

## 三、语言怎么设（这一版的重点）

「更多 → 设置 → 常用功能」里有四个独立的下拉：

| 项 | 你该怎么选 |
| --- | --- |
| 界面语言 | 本版只有简体中文 |
| 你理解的语言 | 你读哪种语言最轻松（字幕和释义会用它） |
| 我想说的语言 | 你要开口说的是哪种 |
| 读音提示 | 汉字近音 / 片假名近音 / 罗马字 / 不显示 |

下面还有「口音／地区」（`en-US`、`en-GB`、`ja-JP`）和「朗读语音」状态。

**做透的三个方向**（界面里也写着）：
- 中文 → 英语（汉字近音）
- 日本語 → 英語（片假名）
- English → 日本語（罗马字）

其它组合能选、能跑，但没做过人工核对，界面会写「不在实测清单内（可用，但未核对）」。

### 读音提示是怎么显示出来的

- 每个词一段提示，点原文里某个词，提示行对应那段会同时亮起。
- 打不到的词（词典里没有的汉字）**不编读音**：画一条虚线，并标「部分未确定」。
- 所有提示都是**近似**，不等于标准发音。界面上每处都写着这句话。

---

## 四、双面沟通卡

回复卡右上角「给对方看」：

- **对方那面**：只有一句 30px 的大字原文。没有说话按钮、没有释义、没有注音——对方不需要知道你怎么念。
- **自己那面**：释义 + 读音提示 + 原文，还有「朗读（需手动点）」「慢速」。
- 翻面用「看我的那一面／给对方看」，关闭按 Esc 或「关闭」。

**它不会自动朗读，也不会发送给任何人。** 要不要出声、要不要把屏幕转过去，永远是你决定。

时间/金额不确定时：关掉卡片，在「重点信息」里勾上那几条，点「帮我确认」，会生成一句「我理解的是……，对吗？」。

---

## 五、字号（三类独立）

- 音源条上有「调整对象：原文 / 译文 / 谐音」，选一种，再点 A− / A+，**只改这一类**。
- 设置页三个滑块（12–64px），每个下面有当前值，点「恢复默认」回 18 / 24 / 18。
- 采集时改立即生效，不用重启；改完写进设置，下次打开还是这个值。
- 关掉读音提示只是不显示，已经存下的内容不会被删。

---

## 六、记录

- 每条字幕都会写进本机数据库，字幕区上方有「已保存／尚未保存」的小标签。**只有真的写进去才显示「已保存」。**
- 记录不设条数上限，也不会自动清理。
- 看历史时顶部会有「加载更早的内容」。
- 「记录 → 备份」用 `VACUUM INTO` 生成一致快照；恢复时先完全退出软件再替换文件。

---

## 七、常见问题

**Q：字幕是空的，但状态写着「正在监听」。**
A：先点「一键诊断」。最常见的原因是服务商余额不足（会返回 HTTP 402）或者语音识别 Key 没填 —— 这两种都不是「没听到声音」。

**Q：点了朗读没声音。**
A：设置 → 常用功能 → 朗读语音，看它写的是不是「缺少 en-US 语音」。本机若只装了中文语音，软件会**明确报错**，不会拿中文声音去念英语。去系统设置里装一个英语语音包再回来。

**Q：换了理解语言，以前的记录会不会被改？**
A：不会。每条记录都存了当时的提示体系，旧记录显示的还是当时那行字。

**Q：会不会偷偷录音？**
A：不会。音频识别完就丢，磁盘上没有录音文件。

---

## 八、卸载与升级

- 升级：直接装新版，设置与记录都在用户数据目录里，不会被覆盖。
- 卸载：安装程序勾「删除数据」才会连记录一起删。
- 升级前建议先做一次「记录 → 备份」。
