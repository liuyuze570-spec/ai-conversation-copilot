| 横向溢出（常规） | 无 | — |

**自检中发现并修掉的真问题**（不是测试问题）：

1. 跳过启动时不回推状态 → 演示模式下整场写「正在连接音频…」而字幕在滚。
2. `no-audio` 状态没有对应分支 → 状态条写「正在连接」，下面详情写「已采集 5 秒没听到声音」，自相矛盾。
3. 事实卡 + 回复面板同时打开时，字幕区高度被压到 **0**。
4. 演示模式没有电平 → 状态条一直「暂未收到声音」，与正在滚动的字幕冲突。
5. 标题栏与音源条重复显示同一句状态文字。

**证据等级（必须区分）**

- 上面的 PASS 是**规则逻辑**的结果，**不是**语音识别准确率。
- 真实链路（真实音频 → 真实 STT → 真实 LLM 翻译）**未执行**：本机没有可公开的
  真实会议录音，且服务商账户余额不足（返回 HTTP 402）。执行方法见第五节。

# 2. 逐条对照三组样例，记录：
#    输入与音源 / 预期关键信息 / 实际转写 / 实际译文 /

## 七、打包版验证（已执行）

- 构建：`npm run build` → `npm run dist:win`（走 ASCII 暂存目录，项目路径含中文时
  直接打包会让 app-builder 崩溃）。
- 进包核对：用 `asar.extractFile` 取出 `dist/renderer/assets/index-*.js` 与本地
  `dist/renderer/assets/` 做**字节比对**（压缩后函数名会变，grep 函数名不能当证据）。
- 打包版启动：需清除 `ELECTRON_RUN_AS_NODE=1`，否则 exe 秒退、stdout 为空。
- 结果见 `docs/打包核对-v0.4.0.md`。

## 八、这次改动带来的回归风险（自查）

| 风险 | 处理 |
| --- | --- |
| 首页重构导致老快捷键 / 老入口找不到 | 场景、语气、中文输入移入「更多」，`Alt+V` 等快捷键未改；自检覆盖场景切换 |
| 字号步长 2px → 1px | 18–40 共 23 档，边界按钮置灰；自检从 23 点回 23 |
| 删除独立电平条 | `data-audio-db` / `data-audio-live` 移到音源条，数值口径不变 |
| 演示模式新增电平推送 | 只推 `source: 'system'`，设备名写「演示语料」，不伪装成真实设备 |
