# 上线指南：CI/CD 与 AWS（给不懂技术的人）

> 这份指南是给**完全不懂技术**的人看的。你只需要做「注册账号」这一步，
> 剩下的推代码、触发流水线、部署 AWS，都可以交给我来操作。
> 但**注册账号和绑定支付方式这两步，只有你本人能做**，因为需要你的手机号、
> 邮箱、密码，我不能替你输。

---

## 一、先搞清楚：为什么有两个「你必须亲自做」的坎

| 要做的事 | 为什么只能你本人做 | 你需要做什么 |
|---|---|---|
| 注册 GitHub 账号 | 需要你的邮箱 + 设置密码 | 花 5 分钟注册 |
| 注册 AWS 账号 | 需要邮箱 + 手机号 + **绑信用卡** | 花 10 分钟注册（会先扣 1 美元验证，会退回） |

**这两步做完，其余全部交给我。** 我会上你电脑帮你把代码推到 GitHub、看着流水线跑绿，
再一步步部署 AWS。

---

## 二、第一步：注册 GitHub（5 分钟）

1. 打开浏览器，访问 https://github.com
2. 右上角点 **Sign up**（注册）
3. 填邮箱、设一个密码、取个用户名（随便，比如你的名字拼音）
4. 邮箱会收到一封验证邮件，点里面的链接确认
5. 完成后，把 **用户名** 和 **邮箱** 告诉我（**密码不用告诉我**）

> 做完这步，我可以帮你把整个项目推到 GitHub，CI 流水线就会**自动开始跑测试**，
> 你能在网页上看到一个绿色对勾，证明"CI/CD 是真实运行过的"。

---

## 三、第二步：注册 AWS（10 分钟，需绑信用卡）

1. 打开浏览器，访问 https://aws.amazon.com
2. 右上角点 **Create an AWS Account**（创建账户）
3. 填邮箱、账户名
4. **绑定一张信用卡**（AWS 会扣 1 美元验证身份，几天后自动退回；免费额度内不产生费用）
5. 手机号收验证码，填入
6. 选「Basic 支持计划」（免费的）
7. 完成后，**不要把信用卡号、密码告诉我**。只需要告诉我"注册好了"，以及你登录后的
   **区域**（比如想用哪个地区，默认 us-east-1 弗吉尼亚即可）

> ⚠️ 重要提醒：AWS 免费额度（Free Tier）内部署我们这个项目**基本不花钱**（每月约
> $50–70 的按量计费是我们预估的**满负荷**价，演示/低流量用免费额度基本够）。
> 但 AWS 绑卡后，如果你自己乱点开了贵的服务（比如大规格实例、GPU），可能产生费用。
> 所以**注册好之后别再自己点，交给我操作**，我会用最小规格 + 用完即删。

---

## 四、注册好之后，我帮你做什么（你啥都不用管）

1. **推 GitHub**：我把代码推上去，CI 流水线自动跑，给你看绿色对勾的截图。
2. **部署 AWS**：我按 `docs/网站AWS部署方案-0.7.0-web.md` 一步步来：
   - 构建 Docker 镜像 → 推到 ECR
   - 用 Terraform 拉起 ECS（容器）+ EFS（存反馈的硬盘）+ ALB（对外访问入口）
   - 配 HTTPS 证书 + 域名
3. **验收**：部署完我会自己测一遍（提交反馈 → 重启 → 确认反馈还在），把结果给你。
