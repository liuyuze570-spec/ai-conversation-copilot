| 检查 | 结论 | 证据 |

| 按钮有准确名称 | 实测：`aria-label` = 「缩小中文译文字号，当前 24 像素」/「放大…」 | `1-font-controls` |

| 调谐音不动译文 | 实测：谐音 18→24，译文仍 `26px`、原文仍 `18px` | `7-adjust-romanization` |

| 互不影响（纯函数层） | 规则：`adjustFontSize` 只改目标键，其余两个键原样 | 单测 J4–J10 |

## 二、高对比

| 检查 | 结论 | 证据 |
| --- | --- | --- |
| 确实换了底色 | 实测：打开后根节点 `background-color` = `rgb(0, 0, 0)`，`data-contrast="high"` | `10-high-contrast` |
| 文字确实变纯白 | 实测：原文 / 译文 `color` = `rgb(255, 255, 255)`（不再半透明） | `10-high-contrast` |
| 对比度用真实渲染色算 | 实测：`getComputedStyle` 读出的白字 + 纯黑底 → **21:1** | `11-contrast-measured` |
| 普通模式对比度 | 规则（按配色表计算，含 alpha 合成）：译文 14.92:1、原文 17.73:1；旧的 `white/45` 只有 4.51:1 | 单测 E17 / E20 |

> 说明：普通模式那两个数字是**按配色表计算**的值，不是读渲染结果；
> 高对比的 21:1 是**读真实渲染色**算出来的。两类证据分开写，不混。

## 六、本轮走查发现并已修掉的问题

| 问题 | 怎么发现的 | 处理 |
| --- | --- | --- |
| 样例面板关闭后 `inert` 没恢复 | 自检第一次跑出 `panelClosed: false` | 实际是**自检读太早**（同一帧读 React 状态）；脚本改成等卸载，同时确认 `inert` 会恢复 |
| 记录面板显示「共 0 段」 | 自检读到点击后 150ms 的快照 | 同样是读太早；改成等列表出现再读，实测「共 1 段 · 1 条消息」 |
| 历史详情字号写死 12/13/11px | 自检新增 `detailFonts` 断言前，看代码发现 | 改为读 `readingPrefs`，与主字幕同一套；实测 18/26/24 与设置一致 |
| 记录行点不动（详情为空） | 自检 `detailMessages: 0` | `[data-history-session]` 是外层 div，可点的是里面的 button；脚本改为点 button，`detailMessages: 1` |
| 首次启动的隐私说明还写着「记录只存在内存里，关掉即清空」 | 截图肉眼看到 | 改成 6 条真实说明，并加「本地保存不等于加密」；自检 `0b-privacy` 断言已无该旧文案 |
| 关闭重开后字幕区一片黑，像丢了记录 | 自检 `07-after-reload.png` | 空状态新增「上次的记录还在本机 + 打开这段」，实测点开后原文/译文/谐音逐字段一致 |
