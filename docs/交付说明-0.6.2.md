## 6. 三组可体验样例和主要变体

打开软件 → 顶部是橙色横幅「演示模式：听不到电脑里的声音」→ 理解语言 = 中文，目标语言 = 英语。
样例面板「三组样例」里点一条，就能看到字幕 / 译文 / 读音提示 / 回复 / 重点信息。

| # | 原话 | 应该看到什么 |
| --- | --- | --- |
| 1 | `Please send the report by 3 p.m. tomorrow.` | 译文「请在明天下午三点前把报告发过来。」；提示 `普利斯 森德 德 瑞波特 拜 3 皮艾姆 特莫柔` |
| 2 | `The meeting is not on Tuesday. It has moved to Thursday at 10:30 a.m.` | 重点信息里**周二显示「被否定」**、周四「待确认」；勾选后能生成「我理解的是周四上午 10:30，对吗？」 |
| 3 | `The budget is 15,000 dollars, not 50,000.` | 15000 为有效值、50000 被否定；确认句里只有 15000 |

**这一版最该现场演示的一条（第 2 条样例上继续做）**：

1. 打开「重点信息」，找到 `时间 10:30 a.m`，点「修改」，改成 `11:30`；
2. 勾上它 → 点「帮我确认」→ 读到 `Just to confirm, 11:30 a.m. Is that right?` 与 `我理解的是11:30，对吗？`；
3. 再点「修改」，把日期改成「还没定」→ 这一行出现**「需补说法」**，旧草稿立刻作废
   （推不出英语说法时宁可拦住，也不拿旧句子配新中文）。

主要变体（都验过）：

| 变体 | 结果 |
| --- | --- |
| `15,000 → 16000美元` | 中英两边都是 16000/16,000，旧值不出现 |
| `10:30 → 11:30` | 中英两边都是 11:30，`a.m.` 保留且不叠句号 |
| `3 p.m. → 上午10点` | 小时与上下午一起换（`10 a.m.`） |
| `15000美元 → 15000日元` | **拒绝生成**，提示「单位对不上，点改说法」 |
| 理解语言切到日本語 / English | 三条样例的译文与释义跟着变；没有预置就明说，不拿中文顶替 |
| `Tomorrow.` / `Next week.` / `See you tomorrow.` | `明天。` / `下周。` / `明天见。`（日语方向：`明日。` / `来週。` / `また明日。`） |
| `Thanks a lot.`（没预置整句） | `〔演示模式只认出关键词：…〕Thanks a lot.` —— 明确标出是关键词，不冒充整句翻译 |

另外：`node .dev/reading-list.mjs` 会把 10 句常用表达的真实读音逐段打出来（只导出程序会显示什么，不判对错）。
