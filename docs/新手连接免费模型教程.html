API Key

模型
（Model）		 会说话的大脑。不同大脑有聪明和快速的差别。 软件里用下拉框选一个。名字旁写「免费」的不花钱，新手就选这个。
服务商
（也叫「平台」「开放平台」）		 卖大脑的商店。你要去商店里领钥匙。 从下面三家免费的里挑一家。新手直接用「硅基流动」，一把钥匙连字幕都管。
为什么只让连国内的网站？ ① 连得上：国外接口在国内经常直接连不通，要多装一堆东西，还老断。
② 更安全：你电脑里的声音、看的电影、说的话，不会发到境外去。
③ 更省钱：国内这几家的免费额度比国外大得多，普通人够用几个月。
所以软件会主动挡住国外地址 —— 这是故意设计的保护，不是坏了。

Q常见疑问

真的可以一直不花钱吗？会不会偷偷扣钱？

可以。免费模型是服务商自己定价 0 元，不是先免费用、后补扣。 你要做的只有一件事：只选带「免费」字样的模型。 余额和用量在服务商后台随时能看，充值是手动行为，不开自动续费就不会自动扣。

我完全不懂电脑，能学会吗？

能。整件事只有两个动作：在网页上复制一串字符、在软件里粘贴。 和你平时复制一个网址发到微信里，是一模一样的操作。唯一要记住的是：钥匙别给别人看。

为什么教程推荐硅基流动，而不是最"大牌"的那家？

因为它是唯一「一把钥匙同时管文字回复和语音字幕」的免费选项。 新手最怕的就是「配了两把钥匙，不知道哪把错了」。先用一把能跑通，以后再换别家随时可以。

我手里已经有一把 Key，但不知道是哪家的怎么办？

看它从哪个网站拿的：cloud.siliconflow.cn 是硅基流动、 open.bigmodel.cn 是智谱、modelscope.cn 是魔搭、 platform.deepseek.com 是 DeepSeek。 回软件把「第 1 步」的服务商改成对应那家，再粘贴，然后点「测试连接」。 服务商和钥匙必须是同一家，串了会报「Key 没有权限」。

为什么必须用国内的模型？用国外的行不行？

软件故意只允许国内地址：① 国内直连，不用额外工具，更稳更快； ② 你的声音和对话内容不会发到境外；③ 国内免费额度多得多。 这是产品的硬规则，不是故障。

换电脑、重装系统之后要重新弄吗？

要重新填一次钥匙。钥匙是加密绑在这台电脑上的，换机器就解不开。 但服务商那边的钥匙还在，登录进去再复制一次就行，不用重新注册。

想把软件发给朋友，要注意什么？

直接发安装包就行，朋友双击装好就能用，不需要装 Python 或别的东西。 只有两件事你得提醒他：
① 安装时 Windows 可能弹蓝色窗口，点「更多信息」→「仍要运行」（软件没有购买数字签名，请确认安装包来自你信任的渠道）；
② 钥匙必须他自己去领——你的钥匙加密绑在你的电脑上，拷过去也解不开； 而且多台电脑共用一个免费 Key，会被服务商判定异常、两边一起报「请求太快了」。

我不想联网、不想填钥匙，能用吗？

可以先用演示模式看界面长什么样（设置 → API 功能 → 最下面）。 但演示模式听不到电脑里的真实声音，只用来熟悉按钮。

朋友装完打开是空的，是不是坏了？

不是。新装的软件默认是真实监听，但还没有钥匙，所以不出字幕。让他看两处：
① 音量条会不会跳 —— 会跳说明声音进来了（这一步不需要钥匙）；
② 中间那段字会直接说「已经听到声音了，只差一个语音识别 Key」。
跟着本教程领一把钥匙填进去，字幕立刻就有。

最后一句总结：选一家 → 手机号注册 → 创建密钥 → 复制 → 粘进软件 → 点「测试连接」→ 看到绿色就成了。

还是不通？设置 → 常用功能 → 一键诊断。它会说明白是「地址」「钥匙」「模型」还是「余额」的问题，比凭感觉猜快得多。
