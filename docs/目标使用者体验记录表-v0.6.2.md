## 三、任务脚本（四条，按顺序）

每条都写清：怎么开场、要观察什么、什么算「独立完成」。
**判定标准只看他有没有做成这件事，不看界面好不好看。**

### 任务 1：让对方再说一遍（约 6 分钟）

**开场**：「假设对面的人在跟你说话，你没听清。用这个软件让他再说一遍。」

**场景**：先在软件里放一句英文语音（或让演员说 `Your flight is delayed until 6:40.`），
然后使用者需要：看懂字幕 → 发现没抓住 → 让软件生成「请再说一遍」这类回应 → 给对方看或播放。

**观察项**：

- [ ] 他知道要往哪儿点（不用提示就找到了回应入口）
- [ ] 生成的句子是英文，不是中文
- [ ] 他把这句话**给了对方**（点了「给对方看」或播放），不只是生成完就停
- [ ] 卡住的话，卡在哪一步：□ 找不到入口　□ 不知道要选哪句　□ 生成后不知道下一步

**算独立完成**：全程没被提示就做完了「生成 + 给对方」。

### 任务 2：核对「周四 10:30」（约 8 分钟）

**开场**：「对面说会议改时间了。你要确认自己没听错：到底是周几、几点。」

**场景**：放 `The meeting is not on Tuesday. It has moved to Thursday at 10:30 a.m.`
（这条在演示模式下有预置译文与预置回复，见《三组样例》文档。）

**观察项**：

- [ ] 他注意到「周二」被否定了（不是简单地把两个日期都当有效值）
- [ ] 他从重点信息里勾出了「周四」和「10:30」
- [ ] 他生成了确认句，并**自己决定**是展示给对方还是朗读
- [ ] 他**手动**记录了核对结果（不是软件自动标成「已确认」）
- [ ] 卡住的话，卡在哪一步：□ 没看见重点信息　□ 勾选操作不顺手　□ 不知道怎么确认

**算独立完成**：说出了「周四上午 10:30，对吗」这个意思，并且没有把周二当成有效时间。

### 任务 3：核对「15000 不是 50000」（约 8 分钟）

**开场**：「对面报价，你怕听错数字。确认一下到底多少钱。」

**场景**：放 `The budget is 15,000 dollars, not 50,000.`

**观察项**：

- [ ] 他看出 15000 是有效值、50000 是被否定的
- [ ] 重点信息卡上两个数都在，且关系看得懂（不是并列两个陌生数字）
- [ ] 他生成了确认句，句子里是 15000 不是 50000
- [ ] 他手动记录了核对结果
- [ ] 改过大字号之后还能做完（可让他在任务 3 中途把字幕调大一号再继续）

**算独立完成**：能说出「一万五，不是五万」这个意思。

### 任务 4：改一个值，再重新确认（约 8 分钟）

**开场**：「对方说的是 10:30，但你后来确认其实是 11:30。把这条改过来，再问一遍对方。」

**场景**：先用任务 2 那句「会议改到周四 10:30」，然后在使用者不知道「标准答案」的情况下，
要求他把时间改成 11:30 并重新生成确认句。

**为什么要单独测这一条**：这正是 v0.6.2 修的那个坑 —— 以前改了值以后，英文句子还念旧的
10:30，中文释义却显示 11:30，用户照着念就会当场说错。所以这一条要重点观察「他有没有发现
屏幕上两个地方说的不是同一个时间」。

**观察项**：

- [ ] 他能找到「修改」并改掉时间（不用提示）
- [ ] 改完那一行会显示「已从「10:30 a.m」改为「11:30」」
- [ ] 生成的英文句子念的是 **11:30**，中文释义也是 **11:30**
- [ ] 改完之后，这一行从「已确认」回到「待确认」（说明旧确认没有继续给新值背书）
- [ ] 如果他把值改成了推不出说法的内容（例如把日期改成「还没定」），界面出现「需补说法」，
      并且**没有**给出半截句子
- [ ] 他能不能自己想到点「改说法」去补一句外语

**算独立完成**：改完值以后，确认句里的数字/时间和他改后的值一致，并且他知道要重新确认。

### 收尾（约 5 分钟）

2. 「如果这个东西只能留一个功能，你留哪个？」
3. 「你会拿它用在什么场合？」

## 五、怎么把结果变成改动（不要停在「收集了反馈」）

| 反馈类型 | 处理方式 |
| --- | --- |
| 找不到入口 / 不知道下一步 | 改界面与文案，**不**加新功能 |
| 误解了任务本身 | 先改文案措辞，再考虑改交互 |
| 功能做了但他不用 | 记下来，不要急着删 —— 可能是任务设计问题 |
| 他要求的新功能 | 进「后续计划」，不在比赛前临时加 |
| 与我们的判断相反 | 以他的操作为准，把他的原话留在记录里 |

改完之后**同一个人再测一次**，记录「复测是否改善」。没有复测的改动只能算「改过」，
不能算「改好了」。

## 六、这份表要怎么进材料

- 路演第 5 页只写**真实做过的数字**（例如「1 名使用者，3 条任务，2 条独立完成，1 条卡在确认句」）。
- 一条都没做时，那一页写「目标使用者实测：未执行」，**不留空白也不写「反馈良好」**。
- 发音核对（母语者听）与可用性测试（听障者用）是**两件不同的事**，分开记录、分开写结论。
  一个英语母语者说「发音挺准」不能证明听障使用者能独立完成任务。
