## 第 1 页 · 问题：卡住的地方不是「听不见」，是「说不出口、不敢确认」

**一句话**：听障者戴着助听设备能听见声音，但在英语会议里，卡住他的往往是
**没法开口**，和**不敢确认自己听对了没有**。

三个卡点（按场景挑的，不是统计排序）：

1. **请对方再说一遍** —— 说不出口，只能点头。
2. **改期** ——「会议不是周二，是周四上午 10:30」，听到的是周二，不敢确认。
3. **金额** ——「一万二，不是两万」，两个数字都在耳朵里，签字前才发现记反了。

现有工具解决「把话变成字」。我们的判断是：光有字幕不够，还得能
（a）看懂、（b）念出来、（c）把关键数字确认下来。

**所以做的是一条链**：声音 → 外语原文 + 你看得懂的译文 → 关键信息一致性检查
→ 一句能直接说出去的确认句 → 可以改、可以记下来的事实卡。

## 第 2 页 · 这一版修的，是「确认卡在帮你确认一个错的值」

**真实 bug（2026-11-08 实测输出）**：模型把 `not twenty thousand` 译成「不是 2 000」，
还多出一个原文没有的「提前」。用户照着念，对方听到的就是错的金额和错的方向。

**修法分两层，都不许硬编码**：

1. **一致性检查**（`numeric-check.ts`）：把原文和译文里的数值、时间点、星期、
   否定关系、提前/延后方向分别扫出来比对。译文里多出来的数 **就地标红**，
   但不改译文——暗改等于替用户做决定。
2. **确认句同源**：句子和释义都从「当前理解」出发；改过的值必须出现、改前的值不许出现；
   推不出来（换币种、换地点）就**拒绝出句**，让用户自己补一句。

**今天又补了两个洞（v0.7.0）**：

| 洞 | 表现 | 修法 |
|---|---|---|
| 英文单个的数词读不出来 | `platform two` 读不出 2 → 译文「2 号站台」反被报「原文没有 2」；`three people` → 「两个人」完全漏检 | 补单独数词 / 连字符 / `a hundred`；`one` 当代词时不算数 |
| 中文释义夹英文 | 释义是「我理解的是 twelve thousand」 | 接入中文口语化：`一万二千`、`下午4点`、`下周一` |

实测对比（同一句，真实模型输出）：

```
原文  The train leaves at seven forty-five from platform two.
修复前警示  译文里的「2」在原文中找不到；译文里的「745」在原文中找不到
修复后警示  译文里的「745」在原文中找不到（原文是 seven = 7 / forty-five = 45）
```

> 状态：`已实测`。`745` 本身没修——`room 745` 同样会被改错，所以只提醒、不改写。

## 第 4 页 · 无障碍：不是「加了 aria」，是每一项都点过

背景 `inert`、手写 Tab 环、Esc 关闭、关闭后焦点回到触发按钮。

`webapp/e2e/probe.mjs`（真 Chrome，26 项，全过）里挑几项：

| 项 | 实测 |
|---|---|
| 大字卡 Tab / Shift+Tab | 焦点始终在弹层内，背景 `inert=true` |
| Esc 关闭 | 焦点回到「查看大字卡」，背景解除 `inert` |
| A− / A+ | 同时调原文与译文；连点 20 次封顶 48/56px，连点 30 次停在下限 16px |
| 320px 宽 | 无横向溢出，主按钮右边界 135px |
| 200% 缩放 | 无横向溢出，输入框仍有 384px |
| 高对比 | `body` 底色 `rgb(11,14,20)` → `rgb(0,0,0)`，真换底色 |

自动化：**15 套 / 1157 条 / 0 失败**；接口级事实回归 5 句全过；网页端到端 8 步全过。

## 第 5 页 · 边界与下一步

**今天不能说出口的四句话**：

1. 「云端模型效果很好」—— 没有 Key，一次都没跑过。
2. 「翻译准确率高」—— 新句样本只有几句，没有评测集。
3. 「听障用户体验良好」—— 0 位真实使用者。
4. 「桌面 App 已离线」—— 只有便携版做到了，App 还没接。

**下一步（按价值排序）**：

1. 把本地引擎接回 Electron：App 已有 `vendor/python-runtime` 和边车启动逻辑，
   缺的是「本地引擎进程 + 主进程转发 + 界面上的设备内离线状态」；
2. 真找 1–2 位目标使用者，用固定脚本走一遍三个场景，记录原话；
3. 用系统级断网（防火墙出站规则）再验一次离线。

**路演现场 3 步演示**（每步都有失败预案）：

1. 打开离线便携版 → 输入 `The budget is twelve thousand, not twenty thousand.`
   → 看中文译文 + 两张金额卡（一张标「被对方否定，不作数」）；
2. 把金额改成 `13,000` → 确认句跟着变 → 打开大字卡（Esc 关闭，焦点回原位）；
3. 断网演示：用 `启动（断网自检）.bat` 起服务，翻译与识别照常，退出时「出站拦截 0 次」。

失败预案：模型加载失败就用预置样例（界面会明确标「预置演示」）；
网络不通就只演示离线版；**任何一步失败都直说，不跳过**。
