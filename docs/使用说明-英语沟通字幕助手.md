# 英语沟通字幕助手 · 使用说明（v0.5.0）

> 面向听障使用者的英语沟通字幕工具。系统声音 / 麦克风 → 英文原文 + 中文译文 +
> 中文谐音，关键信息（时间、日期、金额、数量）单独抽出来，读不懂时有离线沟通卡，
> 每一句都自动存进本机记录，关掉软件也不会丢。

---

## 一、它解决什么问题

线上英语会议、视频课、四六级听力，对方说的话从扬声器出来，但对听障使用者来说
**声音不是可用的信息通道**。常见做法是开自动字幕，但通用字幕工具的问题很具体：

- 字幕在屏幕另一头，焦点在自己要操作的窗口上；
- 只有外语原文，读到一半要靠猜；
- 时间、金额、日期这些**必须准确**的信息，恰恰最容易被听错；
- 一旦某一句没看清，没有任何补救动作可做，只能等对方再说一遍。

这个工具的取舍是：**只做一件事 —— 把"对方刚说了什么"变成能读的中文，并且让读不懂时有事可做。**

## 二、三分钟上手

1. 双击 `AI Conversation Copilot.exe`（未购买数字签名，Windows 会提示
   「更多信息 → 仍要运行」，请确认安装包来自你信任的渠道）。
2. 首次打开会看到隐私说明：它听什么、发给谁、需要什么条件、怎么停下来、
   **哪些内容会存在本机**。
3. 打开「设置 → API 功能」，按内置图文教程领一把 Key 并粘贴保存
   （国内模型服务商，需要自己的账号）。
4. 回到主界面，顶部音源条确认两件事：
   - **音源**：`系统声音 · 线上交流 · 对方音源`
   - **状态**：`正在采集`（没声音时是 `采集中，暂未收到声音`）
5. 让对方说话 / 播放视频，字幕会出现在中部：外语原文在上、**中文译文更大**、
   下面一行是**中文谐音**（给外语标的近似读音）。
6. 想看清哪一种文字就调哪一种：音源条上的 `原文 / 译文 / 谐音` 三个按钮选择
   调整对象，`A−` `A+` 调这一类，当前像素值就在旁边显示。见第三节。
7. 没跟上时：底部三张**离线沟通卡**（请再说一遍 / 请慢一点 / 请把关键时间写下来），
   点开就是大字号英文 + 中文，可以直接给对方看，也可以复制。

不想装 Key 也想先看效果：点底部「更多 → 三组样例」，里面有三句预置文本，
点一下就注入字幕区（**只在演示模式可用**，不会调用付费接口）。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt + P` | 暂停 / 继续采集 |
| `Alt + Space` | 按当前语境生成一句可以接的话（需要联网） |
| `Alt + V` | 切换场景：实时对话 / 看视频 / 四六级听力 |
| `Alt + X` | 关闭回复面板 |

## 三、三类文字的字号（这一版重做的地方）

三类文字**各自独立**，改一种不会连带改另外两种：

| 调整对象 | 指什么 | 默认 | 范围 |
| --- | --- | --- | --- |
| 原文 | 对方说的外语原句 | 18px | 12–64px |
| 译文 | 翻译出来的中文（主阅读对象） | 24px | 12–64px |
| 谐音 | 给外语标的**中文近似音**（不是译文、不是拼音） | 18px | 12–64px |

- **在哪调**：首页音源条上的三个小按钮 + `A−` `A+`，当前值实时显示；
  设置 → 通用 → 字幕，有三个独立滑块和「恢复默认字号（原文 18 / 译文 24 / 谐音 18）」。
- **什么时候生效**：立刻。不用暂停、不用重启、不用重新识别，也不会清掉已有字幕。
- **影响范围**：当前字幕、历史记录详情、回复卡里的中文近似音，全部按同一套字号显示。
- **会保存**：写进设置文件，下次启动保持。
- **谐音关掉只隐藏不删数据**：关掉后记录里仍然保留谐音文本。
- 放大到 26px 以上时底栏会自动精简（次要按钮收进「更多」），保证字幕区不被挤没；
  40px 以上再收一档。字幕区始终可滚动，长句会换行，不会横向裁切。
- 谐音是**近似**，用来"照着念一遍"，不等同标准发音；IPA 与云端朗读仍保留，
  不强制使用。

## 四、记录：会自动保存，也能自己管

这一版把「关掉就没了」改掉了。对话内容自动存进本机的 SQLite 数据库
（`history.db`），关掉软件、重启电脑、覆盖安装新版本都不会删。

### 存在哪

- 位置：`%APPDATA%\ai-conversation-copilot\history.db`
  （设置 → 通用 → 记录 里能看到完整路径，按钮「打开记录文件夹」直接打开）。
- **不在安装目录、不在临时目录**：卸载软件不会顺手删掉记录（目录会保留），
  重装后仍能读到；升级新版本用的是同一个文件，不需要手动迁移。
- 存什么：每条消息的时间、说话角色、音源通道、外语原文、中文译文、中文谐音、
  置信度、翻译状态（完成 / 处理中 / 失败 / 已取消）、你改过的内容、
  以及这张字幕上确认过的事实卡条目。
- **不存原始录音**。音频只在内存里过一遍，识别完就丢。

### 什么时候写

- 会话一开始就有稳定 ID；每句字幕**定稿那一刻**写入，译文、谐音、AI 回复
  后续到达时**更新同一条**（不会变成好几条重复记录）。
- 中途有节流（合并 300ms 内的改动），但不需要等退出。异常退出（断电、
  进程被杀）时已经提交的数据仍在，这是数据库事务保证的。
- 字幕区右上角的徽标会说明保存状态：`已保存` / `正在保存…` / `尚未保存`。
  **只有拿到写入回执才显示「已保存」**；失败会显示「保存失败」并给
  「重试保存」，不会假装成功。

### 怎么找回来

- 顶部「记录」按钮 → 打开记录面板：左边是会话列表（标题、时间、语言、条数），
  点一条看详情；搜索框可以搜**标题、原文、译文、谐音**。
- 重开软件后字幕区是空的（那是一场已经结束的对话），空状态会显示
  **「上次的记录还在本机」+「打开这段」**，点一下就把上次的内容读回来。
- 长会话不会一次全加载：一次 50 条，翻到顶部点「加载更早」继续，
  顺序固定、不重不漏；加载后会停在你正在看的位置，不会被拽到最新一句。
- **界面只加载一页，不等于其他内容不存在**：数据在库里，往上翻就有。

### 导出与备份

- 记录面板底部：「导出全部」「备份数据库」「导出这一段」。
- 导出全部 = 一份可读的文本（含原文 / 译文 / 谐音）或一份结构化 JSON，
  分批写入，长会话不会卡住界面。
- 备份 = 数据库的一致性快照（`VACUUM INTO`），不是"复制一个正在写的文件"，
  备份出来能独立打开；建议定期做。
- **不做自动上传、没有云账号**。所有记录都只在这台电脑上。

### 删除

- 删一段：记录面板里那一条的「删除」（会二次确认）。
- 清空全部：面板底部「清空全部」（会二次确认，并说明不可恢复）。
- 字幕区右上角「清空」只清**当前屏幕上的字幕**，**不等于**删除记录。

### 关于隐私的实话

本地保存**不等于加密**。能用你这台电脑的人（或拿到文件的人）可以直接读到
`history.db` 里的文字。如果记录里有敏感内容，用「导出 → 备份」之后自行加密保管，
或者用完就删掉那一段。

## 五、两种音源用途

以前「麦克风」被一律当成"你自己在说话"，所以面对面沟通时麦克风收到的对方声音
**根本不会翻译** —— 界面写着支持，链路其实没走。

现在在「设置 → 音频」先选用途：

| 音源用途 | 采什么 | 谁在说 | 是否翻译 |
| --- | --- | --- | --- |
| 线上交流（电脑里的声音） | 系统声音 | 对方 | 翻译 |
| 同上 + 麦克风 | 麦克风 | 你自己 | 只做口语提示，不翻译 |
| 现场沟通（麦克风听对方） | 麦克风 | 对方 | **翻译** |

现场模式下系统声音会让位（否则同一句话会出两遍字幕），设置页会写明原因。
切换用途会让采集管线按新配置重建（这一版修好了：以前只改界面文字，引擎还用旧路由）。

## 六、出问题时它能告诉你什么

设计原则：**不写"失败了"，写"哪里卡住 + 下一步做什么"。**

| 看到 | 含义 | 怎么做 |
| --- | --- | --- |
| 正在连接音频… | 正在打开设备，通常 1–2 秒 | 停在这里超过 5 秒点「重新连接」 |
| 采集中，暂未收到声音 | 采集在跑，最近 8 秒没有声音进来 | 检查对方是否在说话 / 播放，或换音源 |
| 音频采集失败 | 音频进程没起来 | 点「重新连接」，不需要重启软件 |
| 翻译失败 · <原因> | 保留原文，译文那行给出原因和下一步 | 可逐句重试；原因分联网 / Key / 额度 / 模型 |
| 这里有一段没转写 | 队列积压或识别超时，那句话没进来 | 字幕里保留位置，不假装连续 |
| 保存失败 · 重试保存 | 记录没写进文件 | 点「重试保存」；磁盘满 / 目录不可写会给具体提示 |
| 演示模式：听不到电脑里的声音 | 演示模式只播内置示例 | 点「监听系统声音」切换真实采集 |

「设置 → 音频 → 一键诊断」会真发一次请求，把"Key 在、设备正常、就是没字幕"
这类问题（常见是服务商**余额不足**）直接指出来。诊断只看有问题的项，
没点按钮时不会显示任何结论。

## 七、无障碍设计

1. **三类文字独立可调**：原文 18 / 译文 24 / 谐音 18 起步，12–64px 连续可调，
   互不影响；上限不是"缩回去"，而是窗口里仍能读到、且重要操作仍可达的边界。
2. **译文是主阅读对象**：默认字号最大、亮度最高，不因为"是译文"被压暗。
3. **高对比是真换底色**：开关打开后背景压到纯黑 `#000`、文字压到纯白
   `#fff`（`styles.css` 里的 `[data-contrast='high']` 规则，不只是数字推导）。
   用 `getComputedStyle` 读真实渲染色算出来的对比度是 **21:1**（自检报告
   `11-contrast-measured`）；普通模式的 14.92 / 17.73 是按配色表计算的值。
4. **状态不只靠颜色**：每个状态都有文字、有下一步动作。
5. **纯键盘可完成主流程**：开始/暂停、选调整对象、调字号、切高对比、
   打开沟通卡、进出设置面板、进记录面板全部可 Tab + 回车完成，焦点环 2px 可见。
6. **弹层会真正锁住焦点**：沟通卡、样例面板打开时背景整块 `inert`，
   Tab / Shift+Tab 在卡内循环，Esc 关闭并把焦点还给刚才那个按钮。
7. **控件都有准确名称**：三个字号按钮读作「调整中文译文，当前 24 像素」，
   两个设备下拉分别读作「系统声音设备（对方的声音）」「麦克风设备（你自己的声音）」，
   不再是一排同名控件。
8. **不打断阅读位置**：向上翻历史时新内容不强行跳底；加载更早一页后
   按 `scrollHeight` 差值把视图钉在原处。

## 八、它做不到什么（请先读这段）

- **需要联网 + 自己的 API Key。** 本机的 Python 只负责**采集声音**，
  识别和翻译都在云端完成。断网时它听得到，但出不了字幕。这不是离线工具。
- **音频会发给所选服务商做识别**，文本会发去做翻译。除该服务商外不转发第三方。
  音频不落盘；**识别出来的文字会保存在本机**（见第四节）。
- **不做说话人分离。** 界面上的「对方 / 你」是按音源通道判断的，不是靠声纹识别；
  两个人共用一支麦克风时，角色会混。
- **准确率取决于服务商模型**，代码层不做保证。时间、金额这类关键信息建议
  用「重点信息」卡核对后再行动。
- **中文谐音是近似**，由本地规则生成（不联网、不花额度），不是标准音标，
  也不等同于真人发音。
- **只支持英语输入 + 中文辅助**（另有俄/日/韩，但本版没有针对它们做实测）。
- **演示模式没有 Key 时，那句"译文"是关键词释义**（形如 `明天 / 下周 / 工作`），
  不是完整翻译 —— 它只用来证明界面链路，不能当翻译结果看。
- **本地记录没有加密**，也没有云同步；换电脑不会带过去，需要自己导出。
- 没有代码签名，安装时需要手动允许。
