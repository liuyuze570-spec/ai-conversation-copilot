## 3. 打包版跑同一份自检

```
node .dev/run-v060-pack.js
```

13 秒跑完 10 步，**全部通过**（`release/win-unpacked` 里的 exe，不是源码）：

| 步骤 | 关键读数 |
| --- | --- |
| 语言设置 | 五个字段都在；方向清单文案正确；语音状态「缺少 en-US 语音｜系统现有 1 种语言的声音（zh）」 |
| 设置面板已关闭（2b） | 点 `[data-settings-back]` 后断言面板不在 DOM 里 —— 加这一步是因为前面截图里设置页一直盖在字幕上面，看不出「点词看读音」到底在哪 |
| 点词看读音 | 9 个词 / 9 段提示；点击后原文亮 1 个、提示亮 1 个 |
| 回复面板 | 有释义、提示体系 `hanzi`、有「分句」、有「给对方看」 |
| 双面卡 | 背景 `inert = true`；对方面 30px；自己面释义 + 提示；Esc 关闭；焦点回入口 |
| 记录 | 写 120 条成功；打开后 50 条 → 点「加载更早」→ 100 条 |
| 落盘 | 重开后 18 / 24 / 18，`readingVersion = 2`，语言方向不变 |

跑法说明：用 `--user-data-dir` 指向独立目录。两个原因：用户此刻正开着已安装版，
单实例锁被它占着（新实例会**静默退出**，看起来像自检失败）；也避免动到真实设置和记录库。

> 包内 `resources/docs/` 是**打包那一刻的快照**。如果你手上这份安装包里的《打包核对》
> 把安装包大小写成上一次的读数，或者步骤数比这里少一步，是正常的 —— 以 `release/` 里
> 文件的实际字节数和仓库里 `docs/` 的最新版为准。
