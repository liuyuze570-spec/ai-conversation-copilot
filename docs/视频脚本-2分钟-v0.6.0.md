# 2 分钟备用视频脚本（v0.6.0）

> **状态：脚本已写，视频尚未录制。** 录完把文件放 `docs/video-v0.6.0.mp4`，
> 在提交材料里写上时长与分辨率。录制完成前，**不要把这份脚本当成视频交上去**。

---

## 录之前先定死两件事

1. **定位一句话**：这个工具帮听障使用者**读懂**跨语言的交流内容，然后**用文字回应**；
   读音提示是可选的辅助，软件朗读也是可选的 —— 文字始终在。
2. **哪些是真、哪些是模拟**：画面里凡是出现的字幕，都来自「三组样例」（预置文本），
   样例面板上那行「预置文本，仅演示模式可运行」**不许剪掉**。真实音频链路本轮未跑通
   （服务商余额 HTTP 402），所以视频里不能说「正在识别对方的声音」。

## 录制前检查清单

- [ ] 窗口 460×640，没有被别的窗口挡住；演示模式开关是开的（橙色横幅可见）
- [ ] 三组样例面板里「预置文本」提示完整入画
- [ ] 记录里只有演示内容，没有真实对话
- [ ] 日志里没有 Key 与正文：`grep -c "sk-" logs/app.log`、`grep -c "enc:" logs/app.log` 都应为 0
- [ ] 不出现真实姓名、会议画面、聊天窗口
- [ ] 结尾三行「未执行」必须出现，不要为了好看剪掉
