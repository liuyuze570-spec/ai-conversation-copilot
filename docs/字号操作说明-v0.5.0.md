# 字号操作说明（v0.5.0）

三类文字（外语原文 / 中文译文 / 中文谐音）的字号**互不影响**，
范围统一 12–64px，默认 原文 18 / 译文 24 / 谐音 18。

---

## 一、在首页调（推荐，看字的时候顺手就调）

音源条右侧那一组控件：

```
[原文] [译文] [谐音]   A−   24   A+
 └── 选调整对象 ──┘   └─ 调这一类 ─┘
```

1. 先点一个**调整对象**（`原文` / `译文` / `谐音`），被选中的那个按钮会亮起；
   读屏会念「调整中文译文，当前 24 像素」。
2. 再点 `A−` 或 `A+`，每次 1px；中间的 **24** 是这一类文字的当前像素值。
3. 到 12px / 64px 边界时按钮会变灰（disabled），不会越界。
4. 想同时调两类，就换个对象再点 `A+`。

调的时候**什么都不会中断**：不暂停采集、不重启引擎、不重新识别、不清字幕。
已经显示的字幕和历史记录详情会立刻按新字号重排。

## 二、在设置里调（一次看清三个值）

`设置 → 通用 → 字幕`：

- `外语原文字号` 滑块（12–64）
- `中文译文字号` 滑块（12–64）
- `中文近似音字号` 滑块（12–64）
- `恢复默认字号（原文 18 / 译文 24 / 谐音 18）` 按钮

滑块用键盘也能操作：Tab 到滑块后用 ←/→ 或 Home/End，读屏会念
「中文译文字号 24 像素」。

## 三、会保存在哪里

写进 `settings.json` 的 `subtitle.originalFontSize` / `translationFontSize` /
`romanizationFontSize`，**下次启动保持不变**（本机自检验证：调到
原文 18 / 译文 25 / 谐音 24 后重载窗口，三个值仍为 18 / 25 / 24）。

## 四、作用范围

| 位置 | 是否按设置的字号显示 |
| --- | --- |
| 实时字幕列表 | 是（三行各按自己的字号） |
| 历史记录详情 | 是（同一个组件，读的是同一份设置） |
| 回复卡里的「中文近似音」 | 是（用谐音字号） |
| 沟通卡 / 设置页 / 其它界面文字 | 否（界面文字另有一套尺寸，不受影响） |

## 五、调大了会怎样

- **26px 以上**：底栏自动精简（「我没听清 / 继续话题 / 帮我回复」收进「更多」），
  字幕区不被挤没。
- **40px 以上**：再收一档（连「更多」一起收起），只留必要的入口。
- 长句自动换行，不会横向滚动；字幕区本身可上下滚动，大字时允许滚动查看。
- 重要操作（暂停 / 重连 / 沟通卡 / 调整对象）在任何字号下都在视口内。

## 六、谐音相关

- 「谐音」是给外语标的**中文近似音**，例如
  `Please send the report by 3 p.m. tomorrow.` → `普利斯 塞恩德 德 瑞波尔特 拜 普姆 特莫柔`。
- 它是**近似**，用规则在本地生成（不联网、不花额度），不是标准音标，
  也不等同于真人发音。IPA 与云端朗读仍然保留，不强制使用。
- 关掉谐音显示只是**隐藏**，记录里的谐音文本不会删除。

## 七、已知的边界

- 上限 64px 是在 460px 宽窗口里「仍能读到 + 重要操作仍可达」的实测边界，
  不是随便定的；再大就会出现单词被拆得只剩两三个字母。
- 三类都调到 64px 时，一屏只放得下一句话 —— 这是物理限制，不是 bug。
  往上翻可以看到更早的句子。
- 谐音那一行由本地规则逐词生成，专有名词（人名、品牌）可能不准；
  需要标准发音时看 IPA 或用朗读。
