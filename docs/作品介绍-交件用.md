# AI 对话副驾驶（AI Conversation Copilot）

**听障与英语基础薄弱学生的跨语言沟通助手**

---

## 一、为什么做这个产品

我在普通高校的听障大学生群里，看到不少同学在英语学习上很吃力：英语 AB 级、四六级总是过不去，卡在听力和发音上。这让我开始想，能不能做一个工具，帮他们在需要理解英语、需要开口表达的时候，多一个能帮上忙的东西。

小时候，我用过那种带汉字谐音的英语教材。这段经历给了我一个启发：对一个不知道一句英语怎么读的人来说，谐音也许能帮他迈出第一步——它不能代替标准发音，但可以跟英文原句、中文解释放在一起用。

后来在西安地铁上，我看到一个小女孩，在家长鼓励下主动走向外国人，试着用英语交流。对方很耐心地跟她聊，帮她纠正表达和发音。那一幕我印象特别深，也更让我想把这件事做出来：让需要的人先看懂对方、再试着表达，并且有机会核对、改进。

于是我把汇丰网课里学到的 Python 和 API 知识用起来，从 0.1 版一路做到 0.6.4 版，一点点把想法做成能用的工具。

---

## 二、它做了什么

核心流程就三步：**输入英语 → 看懂、核对关键信息 → 选一句能说出口的回复**。

- **双语字幕**：英文和中文放在一起，方便对照，不认识的地方一眼能找到。
- **关键信息核对**：金额、日期、时间、否定（"不是""不用"）这些最容易听错、记错的地方，会单独抽出来帮你确认。
- **一句忠实回复**：看懂之后，不用自己从头想，可以直接参考一句英文回复。
- **大字展示**：需要给别人看的时候，把文字放大就行。
- **汉字近音**：帮助开口，不是标准音标。
- **事实确认卡**：把确认到的时间、数量、金额记下来，可以改、可以留。

从 0.1 到 0.6.4，我不断补功能：加了日语、俄语、韩语入口，加了不同的语言水平设置；做了能装在本机的 Windows 桌面客户端，也做了能在公网打开的网页版。为了照顾不会配置 API 的同学，我还整理了一份尽量直白的连接教程。

---

## 三、真实用户试用反馈

有一位英语基础薄弱的学生真实试用后，给了这样的反馈：

> 打开网站不用注册，输入英语点一下翻译就能看到中文，基本知道怎么用；英文和中文放一起，方便对照。
> 回复建议和大字展示比较方便——看懂意思后可以参考一句英文回复，不用自己从头想。
> 最需要改的是日期和数量：试了"周二不用交、周四下午交作业"，回复里却同时出现周二和周四，反而拿不准；"450 个单词"也不能只剩"450"。

这两个问题，我们已经在 0.6.4 里修掉了：被"不用"否定的日期不会再混进确认句，数量的单位会保留下来。

## 四、工程是怎么做起来的

- **测试**：24 套单元测试，类型检查 0 错误，全部通过。
- **CI/CD**：代码推送到 GitHub 后，持续集成和构建镜像 + 冒烟测试在 GitHub Actions 上**真实全绿**（可点链接核验）。
- **部署**：翻译和语音识别跑在服务器本地模型上，不是付费云端 API；AWS 部署做过本地镜像演练（推仓库、挂持久卷、起服务都跑通），线上部署还在探索。

它现在还是需要继续打磨的学习与交流辅助工具，但我希望它能让听障大学生和英语基础薄弱的学习者，更方便地看懂、核对、说出英语。
