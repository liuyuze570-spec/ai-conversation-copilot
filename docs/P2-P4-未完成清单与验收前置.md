## 2. P2「翻译其他网页视频」：首版已实现 / 仍未完成

### 2.1 首版已实现（本地 web.9，有真浏览器证据）

- 用户主动点按钮 → `getDisplayMedia({ video, audio, systemAudio:'include' })` →
  **实际检查 `getAudioTracks().length`**；为 0 明确报「没有音频轨」，
  **不退回麦克风、不把画面轨当音频用**。
- AudioWorklet 把音频切成 3 秒、16kHz 16-bit PCM WAV；顺序编号、串行识别队列、
  积压上限 3、静音判定（RMS）、重叠裁剪去重、按词断句（p.m./a.m./小数不误断）。
- 无声音显示「等待声音 · 不会生成字幕」，静音片不上传、不造字。
- 取消 / 停止：abort 在途请求、清空队列、停掉全部轨道（含维持捕获的 video 轨）、
  关闭 AudioContext、撤销 worklet URL。
- 防循环：worklet 输出接 `gain=0` 静音增益，不二次播放捕获到的声音；
  video 轨不接元素、不取帧、不上传。
- 配额改为 **300 秒音频时长预算 + 单片 ≤10 秒 + 识别并发 1 + 90 次/分**；
  片段只做识别/断句/翻译，**不对每小片段生成回复**。
- 端到端延迟实测：978 / 1189 / 631 ms（p50 978，p95 1189，3 条样本）。
  演示、误差记录、兼容表全文见 `docs/翻译其他网页视频-P2演示与兼容表.md`。

### 2.2 仍未完成（不能算 P2 验收通过）

   取消授权、平台不支持、标签页关闭三条失败路径只有代码，没有真人操作录屏。

- 目的：看你能不能**看懂、核对、回复**，不是给产品打分。遇到看不懂、点不到、念不出的
  地方，直接说，都是有用结果。
- 时长约 15–20 分钟；可随时中止。你的输入只在服务端内存里处理（字幕与会话），
  反馈若勾选附带上下文才会写入数据库；**不保存录音、不保存历史对话**。
- 不需要提供姓名、联系方式或听力状况；如愿意，可在最后留一个匿名代号便于复测。
