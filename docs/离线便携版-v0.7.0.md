# 离线便携版（0.7.0-offline）

一个**双击就能用、拔掉网线也能跑**的版本。自带 Python 运行时、翻译模型、识别模型，
不依赖已安装的 App，也不依赖浏览器之外的任何东西。

先说清楚它不是什么：

- **不是** B 盘那个 `AI Conversation Copilot` 的离线版。那个是 Electron 悬浮窗，
  抓的是系统回环音频，代码没动过，还是 0.6.1。
- **不是** 新 App。它是同一套网页界面 + 同一套本地模型，装进一个文件夹里。
- 它是「独立增强版」的第一版尝试：先把**真正断网可用**这条链路走通、量出数据，
  再谈接回桌面端。

构建时间：2026-11-09 10:01（北京时间）

## 1. 目录长什么样

```
offline-web-0.7.0\
├─ 启动.bat               双击启动，自动开一个应用窗口
├─ 启动（断网自检）.bat     带出站拦截启动，关窗口前看「出站拦截 N 次」
├─ 自检.bat               不开窗口，跑一遍翻译 + 识别并打印结果
├─ 版本.txt
├─ python\                自带 CPython 3.12.14 + 依赖（≈440MB）
├─ server\                FastAPI + 两个引擎 + 启动器 + selftest 音频
├─ models\                faster-whisper-base（142MB）
├─ mt-models\             Opus-MT en→zh 量化 ONNX（115MB）
└─ web\                   前端构建产物
```

合计约 **700MB**。体积几乎全在模型和推理运行时上：`av.libs` 131MB（解码音频）、
`ctranslate2` 62MB、`onnxruntime` 43MB、两个模型 257MB。

## 2. 怎么用

1. 双击 `启动.bat`；
2. 它会找一个空闲端口（默认 8765），加载模型（约 1 秒），然后用 **Edge 的应用窗口**
   打开界面——没有地址栏，看起来就是个独立程序；没有 Edge 就退回默认浏览器；
3. 打字或点样例 → 翻译；点麦克风或选音频文件 → 识别。全程不联网。

关掉窗口后，命令行窗口按 Ctrl+C 或直接关闭即可。

## 3. 断网怎么证明

不是「我拔了网线所以应该没联网」，而是**在进程里把所有非回环出站连接拦掉**，
跑完再数拦截次数。0 次 = 整条链路根本没试过联网（不是试了失败）。

`自检.bat` 的实测输出（2026-11-09 10:00）：

```json
{
 "version": "0.7.0-web.1",
 "translate_mode": "local-onnx",
 "transcribe_mode": "local-whisper",
 "translation": "预算是一万二千元,不是二万",
 "translate_ms": 659,
 "transcript": "The train leaves at 745 from platform 2.",
 "transcribe_ms": 584,
 "blocked": 0,
 "ok": true
}
```

（两次自检的波动：翻译 659–822ms，识别 536–584ms。）

同一份包，用 `启动（断网自检）.bat` 起服务后实测：

| 动作 | 结果 |
|---|---|
| `GET /api/health` | `translate=local-onnx`、`transcribe=local-whisper`、`real` 两项 true |
| 翻译 `The budget is twelve thousand, not twenty thousand.` | `预算是一万二千元,不是二万`，**587ms** |
| 识别 `s1-report.wav`（3.4s） | `Please send the report by 3 p.m. tomorrow.`，**531ms** |
| 识别 `o1-platform.wav`（3.9s，未预置） | `The train leaves at 745 from platform 2.`，**477ms** |
| 模型加载 | 翻译 570ms + 预热 364ms；识别 318ms |

界面取证：`docs/evidence-offline/offline-ui.png`（真 Chrome 打开 8765 端口截图，
徽标为「本地翻译模型（真实翻译）」，不是「预置演示」）。

**没做的**：系统级断网（防火墙规则 / 拔网线）需要管理员权限，会打断同机其它验证，
没有做。所以严格说这是**进程级**断网证明，别写成「系统级」。

## 4. 与「离线四层」的对应关系

| 层 | 要求 | 现在到哪一步 |
|---|---|---|
| 1. 基础离线 | 没网也能启动、能用 | **做到**：自带解释器与模型，0 次出站 |
| 2. 新语音离线识别 | 没预置过的音频也能出字幕 | **做到**：两条未预置音频都出真实字幕 |
| 3. 本地英译中 | 不依赖云端翻译 | **做到**：Opus-MT 进程内 ONNX |
| 4. 可靠切换与隐私 | 选本地后不回落云端；恢复联网不上传积压 | **部分做到**：包里没有配任何云端 Key，`provider` 那一路没有可回落的地址；不上传是因为**根本没有队列**（音频识别完即删临时文件），不是靠开关保证的 |

「没有云端可回落」和「有云端但被禁止回落」不是同一件事，后者要接回桌面端才谈得上，
现在不宣称。

## 5. 已知缺陷（别当成已解决）

- **`seven forty-five` → `745`**：识别把口语时间写成数字，译文成「745出发」。
  不改写的原因：`room 745` 同样会被改错。界面对策是原句常显 + 关键信息一致性警示 +
  事实卡可手工改值。
- **回复是模板**：没有文字模型 Key，`reply` 一直走 `mock`，界面标「模板」。
- **麦克风要 HTTPS 或 localhost**：便携版走 `127.0.0.1`，属于可信来源，麦克风可用；
  但换到局域网 IP 访问就不行。
- **体积 700MB**：模型和运行时占绝大部分，暂时没做瘦身。

## 6. 怎么重新生成

```bash
cd "F:/3D打印Rhino 7.0/2026-09-30-23-01-15"
webapp/server/.venv/Scripts/python.exe webapp/build-offline.py          # 覆盖式重建
webapp/server/.venv/Scripts/python.exe webapp/build-offline.py --check  # 只验证包内 import
```

复制的是 `webapp/server/.venv` 里**已经跑通的那批轮子**，不重新 `pip install`，
避免版本漂移把 1045 条单测和离线验证的前提换掉。前端要先 `cd webapp/web && npm run build`。
