## 三、AWS 镜像部署 · ⚠️ 本地镜像演练已跑通，线上未部署

**先给结论**：真实 AWS（ECR/ECS/EFS）**没有部署**，因为没有可用的 AWS 账号密钥；
但「上线要用的那套 AWS 动作」已在本地用等价物**逐项跑通**。详见 `docs/本地镜像AWS验证-20261110.md`。

| 真 AWS 服务 | 用途 | 本地等价物 | 结果 |
| --- | --- | --- | --- |
| ECR（镜像仓库） | 存镜像、部署拉取 | 本地 Docker Registry（localhost:5000） | ✅ 推镜像成功，digest 可查 |
| EFS（持久文件系统） | 反馈库跨重启不丢 | Docker 命名卷（-v …:/app/data） | ✅ 写反馈 → restart → 仍可查 |
| ECS Fargate（无服务器容器） | 跑应用容器 | 本地 docker run | ✅ 健康检查 200、真实翻译 309ms |
| LocalStack（模拟 AWS API） | 本地练 AWS 命令 | — | ⚠️ 卡 token 政策（已停用） |

**本地真实跑通的证据（可复现命令见文档）**：

```bash
# 推本地 Registry（等价 ECR push）
docker push localhost:5000/copilot-web:degraded
# → digest sha256:0373ea…，tags 列表可见

# 完整镜像本地构建 + 真实翻译
docker build -t copilot-web:0.7.0-web.10 -f webapp/deploy/Dockerfile webapp
# → 镜像 2.89GB；/api/translate 返回真实 ONNX 译文「会议于星期四下午4时20分举行。」309ms
```

**与真 AWS 的差异（诚实边界）**：网络（localhost vs VPC/安全组/ALB）、IAM 权限、计费（$50–70/月）、
HTTPS 证书——这些**未实测**。Terraform 模板（ECS Fargate + ALB + EFS + ECR + IAM）已写好于 `terraform/`，
拿到账号密钥即可照做。
