## 第二轮（02:40+）· 母语改下拉 + 回复风格「点不了」根治

### 需求
「设置里的母语改一下，默认为中文和英语；点那个回复风格，怎么老是点不了其他的风格，只能默认自然语言，
想用其他风格的语言回复对方，把这个 Bug 改了。」

### 根因（重要，可复用）
**设置页所有下拉都用了原生 `<select>`**。这个悬浮窗是「无边框 + `setAlwaysOnTop(...,'screen-saver')`
+ 设置面板 `backdrop-blur-xl` + 面板内部 `overflow-y-auto`」——原生下拉的弹出层是操作系统单独开的
窗口，这种环境下会被裁切 / 点不动 / 选中不生效。全应用没有一个下拉做过真实点击验证。

→ 根治：`controls.tsx` 的 `Select` **改为 DOM 自绘弹出层**：
- `createPortal` 到 `document.body` + `position: fixed`。**必须用 portal**：面板祖先有
  `backdrop-filter`，它会让 `position: fixed` 的包含块退回成该祖先，再被 `overflow-y-auto` 裁掉。
- 打开时按触发器 `getBoundingClientRect()` 现算位置；下面空间不足且上面更宽裕就朝上弹。
- **滚动只重新定位、不关闭**。踩过的坑：按钮获得焦点时浏览器会把它滚进可视区 → 触发 scroll →
  菜单在打开的同一帧被自己关掉（症状就是"点了没反应"）。触发器加
  `onMouseDown={(e) => e.preventDefault()}` 不抢焦点，双保险。
- 保留 `value/options/onChange/width/dataAttr` 接口，并额外在触发器上输出 `data-value` / `data-open`；
  **自检里读值要从 `.value` 改成 `getAttribute('data-value')`**（自绘下拉的触发器是 `<button>`，没有 `.value`）。
- `DeviceSelect` 也改成复用 `Select`。

## 第 4 轮：用户反馈「翻译不准 60%、没有中文谐音、切不了回复风格」

用户实跑的是**安装版 0.3.0**（`F:\新建文件夹 (3)\AI Conversation Copilot`），日志里 `python sidecar ... python-runtime（安装包自带）`。
排查出 5 个真 bug（都不是猜的，都有日志/断言证据）：

1. **丢句（最致命）**：`python-engine.ts` 的 `AudioStream.transcribe()` 用一个 `transcribing` 布尔当互斥量，
   撞上在途的「中途识别」就把**最终整句**直接 return 丢掉。2.5 秒以上的人声几乎必然撞上 →
   字幕永远停在低置信度的半句话上，而且它是 `partial`，既不进上下文、也不被翻译。
   → 改成**串行队列**：final 一定跑；排队的 partial 被 final 抢占（`enqueue`/`pump`/`runTranscribe`）。
   同时 VAD 加**迟滞双阈值**、底噪初值 300→120 并限幅、加 `MAX_SEGMENT_MS=12s` 强制收官
   （背景音乐不断时段会无限增长，最后送一整段去识别，只吐开头一句）。
2. **混叠 + 削顶**：`loopback.py` 48k→16k 只用 `np.interp` 线性插值，8kHz 以上会折叠回人声频段（实测 10kHz 残留 0.36 rms）；
   `clean_pcm` 用 `clip(mono*sensitivity)` 音量大时削成方波。→ 加 33 抽头加窗 sinc 低通（10k/15k/20k 压掉 41dB，
   1kHz 损耗 0.7%），增益改自适应 `gain = min(sensitivity, 0.97/peak)`，永不削顶。
3. **翻译竞态**：中途译文和整句译文写同一个卡片 id，先发后到会覆盖正确译文。→ `translateSeqRef`（Map<id,seq>）
   只认最新一次请求；partial 少于 3 个词不翻（避免半句译文乱跳）。
4. **母语设置失效**：`buildTranslateMessages` 把「英语→中文」写死，`from/to` 参数被完全忽略。
   → 改语言感知提示词 + 补「数字/人名保留、截断句不要编结尾」；译文上下文带上上一句译文；温度 0.2→0.1。
5. **回复 JSON 崩了**：真实日志 `"ipa": tʰatz ˈɹaʊf` —— 小模型把音标**不加引号**写出来，`JSON.parse` 直接抛错，
   整个回复变「连接失败」。→ `extractJson` 加三层修复（剥 ` thinking` 块 → 定位 `{"replies"` → 按行给裸值补引号），
   实测能救回日志里那条真实坏 JSON；再加 `response_format: json_object` 和**降级重试**
   `[{json}, {}, {plain}]`（先保延迟再保格式，`plain` 会退回「开着思考」10–20s，所以放最后）。

### 中文谐音（用户说「无法显示」）
- 老提示词写「不需要就留空」→ 弱模型基本不填。改成**英语必填**，并要求「按英文单词逐块音译、空格分隔」。
- 弱模型会**把中文翻译抄进谐音字段**（实测 `"这声听起来很有趣点有什么计划"`）。`enrichDraft` 加判据：
  无汉字 / 与 chinese 相同 / **分块数 < max(2, 词数/2)** → 一律回退本地引擎。
- 本地 `transliterate()` 质量够用（`This sounds interesting. What is your plan?` → `迪斯 桑兹 因吹斯汀 沃特 伊兹 约尔 普拉恩`）。
- **字幕区也加了谐音行**（`data-subtitle-pron`）—— 用户的「无法显示」很可能就是在看字幕区。

### 回复风格（用户说「无法切换」）
- 设置里改风格/长度/水平/语气 → 面板开着就**自动重出三张卡**（`styleSignature` 副作用，先清空旧回复）。
- 面板里加 **风格快捷芯片**（`data-style-chip`），点一下立刻换。
- **坑**：风格行原本是普通行，面板 `max-h-[52%]` + 内部滚动 → 自动滚到底部时风格行**滚到吸顶标题后面看不见**（截图实锤）。
  必须和标题一起放进同一个 `sticky top-0` 容器；新回复到达时 `scrollTop=0`。自检加了 `styleRowVisible` 断言（先强制滚到底再量 rect）。

### 顺带修掉的
- `Qwen/Qwen3-8B` 是推理型，实测一版回复 10–20 秒。加 `enable_thinking:false` + **启动迁移自动换回 Qwen2.5-7B**（日志留痕）。
- `vadSilenceMs` 旧默认 900 → 1100（迁移只动「还是旧默认值」的配置）。
- `ai-errors.ts` 加 JSON 格式错误的专门文案（以前显示成「连接失败」）。

### 自检基建改进（下次别再踩）
- 真实模型慢，固定 `sleep(2600)` 会把「还没回来」误判成「生成失败」→ 改 `waitForCards(20000)` 轮询。
- `.animate-fade-in-up` **同时被字幕项和回复卡片使用**，用它的 `p` 取「字幕译文」会取到回复卡片的译文。
  → 字幕项加 `data-subtitle-item`、面板加 `data-reply-panel`，断言按属性取。

## 第 6 轮：多轮监听 bug + 界面审美（0.3.2）

用户反馈：「第一轮对话暂停的时候，却无法开启第二轮对话监听，无法翻译」，另要求
「界面审美加强，简约高级感，符合年轻人审美」+「进一步升级优化改造」。

### 根因（两条，都是"状态永远回不去"）
1. **`status` 卡死在 `no-audio`**。sidecar 在开机头几秒（还没播视频）会发一次
   `silent`，主进程据此把状态置成 `no-audio` —— 而**没有任何路径把它改回
   `listening`**。renderer 的「停顿自动回复」看门狗又要求 `status === 'listening'`，
   于是这个门槛一掉下去，**整场对话的自动回复永久失效**。这就是「第二轮再也听不到」。
   修复：`src/shared/audio-status.ts#canWatchForPause()` 允许 `listening | no-audio`；
   `src/main/audio/status-heal.ts#signalHealsStatus()` 在 level 有信号时把状态捞回来。
2. **转录队列能被一次卡住的请求永久闩死**。`pump()` 串行 await，STT 客户端超时是
   60s + 1 次重试 = 最坏 120s 队列不动 → 之后每一轮都没有字幕。修复：加
   `TRANSCRIBE_DEADLINE_MS = 25s`（`withDeadline` 包一层，保证调用方一定被唤醒）+
   `MAX_QUEUE_BACKLOG = 4`（丢最老的，字幕不会越落越远）。

### 「多轮对话」变成一等公民
- `conversation` store 新增 `roundIndex` / `lastForeignText`（每个外语整句 +1）。
- 字幕页头、实时翻译条、回复面板都显示**「第 N 轮」**。
- `ui` store 新增 `repliesRound`：新一轮开始后 `roundIndex > repliesRound` →
  回复面板出**「新一轮已经开始了 … 按新一轮重出」**横幅（`data-reply-stale`）。
  这是「第一轮暂停后以为第二轮没被监听」的正面解法。

### 界面审美（真实存在的老 bug 一并修掉）
- 重建设计令牌：`ink-950..600` 表面阶梯 + `line` 三档描边 + 语义色 `ok/warn/danger`
  + `accent` 改靛蓝 `#6d8bff`。全量替换掉 emerald/amber/rose/glass 与即兴的
  `bg-white/[0.0x]`。
- **踩到一个真坑**：Tailwind 3.4 默认 opacity 刻度只有 **5 的倍数**，所以
  `bg-white/8`、`border-white/6`、`bg-danger/12` 这类类名**不报错也不生成 CSS**，
  一直静默失效 —— 这才是「层级糊、不精致」的物理原因。已在 `theme.extend.opacity`
  把 0–100 补全。（以后加新色值先跑一次 CSS 产物核对。）
- 组件层：TitleBar 加品牌标记 + 呼吸波形；AudioMeter 收敛；LiveTranslateBar 加轮次
  徽标；SubtitleList 层级重排 + 「对方/你」中文标签 + **字幕可点朗读**；
  ReplyCard 加左侧色轨；QuickActions 场景/语气改分段控件；设置页标题吸顶；
  横排选项加 `.fade-r` 右侧渐隐；原生 range/checkbox 用 `accent-color` 对齐主题。
- 顺带性能：`pronunciation.ts` 加词级 + 句级缓存（字幕区每次 partial 都会对**所有**
  字幕重算谐音，没缓存时字幕一多是真拖后腿）。

### 验证（都是实测，不是推演）
- `node .dev/status-heal-unit.mjs` → **11/11 PASS**（import 的是 `dist/` 编译产物，
  即真正跑在用户机器上的那份代码）。
- `node .dev/multi-round-repro.js 40` → `autoPause = 16` 次连续触发（演示模式连播）。
- 自检新增断言全绿：`subtitleRound='第 3 轮'`、`liveRound='第 2 轮'`、
  `replyRoundBadge='第 2 轮'`、`staleShown=true`、`staleClearedAfterRefresh=true`、
  `replyRoundAfterRefresh='第 3 轮'`；历史项无回归（`styleRowVisible`、
  `subtitlePronHasChinese`、`examKindLabels`… 全绿）。
- **真实音频链路这次没验成**：`.dev/status-heal-test.py` 报 BLOCKED —— 沙箱持续
  拒绝 Electron 侧 `spawnSync`（`EBUSY`），sidecar 起不来。脚本已能区分
  「环境挡住」与「修复失败」，别把 BLOCKED 当 FAIL。
