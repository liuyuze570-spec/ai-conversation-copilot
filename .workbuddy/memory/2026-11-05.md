# 2026-11-05 · v0.3.6 → v0.4.0（参赛改进）

## 做了什么

围绕「面向听障使用者的英语沟通字幕助手」重做首页与音频状态，补齐无障碍与交付材料。

### 新增共享纯函数层（全部可单测）
- `shared/audio-state.ts`：`AudioPhase` 六态 + `audioUiState()`；`SIGNAL_WINDOW_MS=8000`、`SIGNAL_DB_FLOOR=-55`、`pushSignal`/`hasRecentSignal`。
- `shared/sources.ts`：`SourceMode='online'|'onsite'`、`speakerOf()`、`resolveSources()`。现场模式麦克风 = 对方且要翻译；线上模式麦克风 = 自己且不翻译。
- `shared/reading.ts`：译文 18–40（默认 23）、原文 12–32、三档阅读模式、`readingPrefs()` 迁移、`contrastOf`（**先 alpha 合成再算**）、`needsCompactChrome(≥26)`。
- `shared/comm-cards.ts`：三张离线沟通卡（again/slower/write）+ `cardClipboardText()`。
- `shared/samples.ts`：三组样例（时间 / 改期否定 / 金额纠正）。

### 主进程
- `audio-controller.ts` 重写：`waitUntilReady` 拿 sidecar `started` 才算成功；`pending`/`failed`/`skipped`/`running` 四态回执；`handleEngineDead` 清指纹；新增 `IPC.AUDIO_RECONNECT`。
- **新增 `engineReady` 标记**：跳过启动时必须回推真实状态，否则渲染层自己写的「正在连接」永远留在界面上（自检发现）。
- `python-engine.ts`：`whenReady/settleReady`、设备回退可见化、丢段 `onDropped`、`onLevel` 上报。
- `mock-engine.ts`：`pulseLevel()` —— 演示模式每句末尾推电平（`source:'system'`、设备名「演示语料」），否则状态条永远「暂未收到声音」。
- `settings-store.ts`：`migrateReading()`、`sourceMode` 推断；Key 相关日志只记错误名（`errorCode()`）。
- `ai:translate` 返回结构化 `{ok,text,cancelled?,error}`。

### 渲染层
- 新建 `SourceBar`（音源 + 状态 + 开始/暂停/重连 + A±1px + 高对比 + 2px 电平线）、`CommCards`（dialog + 焦点归还 + 30px 纯白）。
- `SubtitleList` 重写：双语分字号、译文四态带原因、丢段标记混排、`min-h-[88px]` 保底。
- `QuickActions` 重构：基础层 = 沟通卡 + 更多；场景/语气/中文输入进「更多」；实时对话不再有整行主按钮。
- `TitleBar`：只留一句话状态；`IconButton` 用 `label/hint/pressed`。
- `SettingsPanel`：`role=dialog` + 焦点移入/归还 + Tab 陷阱 + Esc 关闭。
- `controls.tsx`：`RowLabelContext` 让行标签自动成为控件名；自绘 `Select` 补 ↑↓/Enter/Esc/Home/End/首字母 + `aria-activedescendant`。
- `styles.css`：`:is(...):focus-visible` + box-shadow（Tailwind 的 `focus:outline-none` 会吃掉 outline，靠 box-shadow 兜）。
- 删掉 `AudioMeter.tsx`（并入 SourceBar）。

### 测试
- 新建 `.dev/competition-unit.mjs`（115 条），`npm run test:unit` / `test:all`。
- 全套 525 条断言：115+181+69+53+80+16+11，退出码 0。

## 自检抓到的真问题（都修了）
1. 跳过启动不回推状态 → 整场写「正在连接」。
2. `audioUiState` 缺 `no-audio` 分支 → 状态条与详情自相矛盾。
3. 事实卡 + 回复面板同开时字幕区高度 = 0。
4. 演示模式无电平 → 「暂未收到声音」与滚动字幕冲突。
5. 标题栏与音源条重复同一句状态。
6. `log('reply failed: raw.slice(0,200))` 把服务商原文写进日志。

## 踩到的坑
- `--user-data-dir` 可绕开与已安装版的单实例锁；但新目录没有 `Local State`，DPAPI 解不开 Key → 自检里 AI 调用必然失败，属预期。
- 自检里 `setSettings` 只写主进程存储，渲染层 zustand 收不到 → 测 UI 必须点真实按钮。
- 字号步长 2px 时 23 这种奇数回不去 → 改 1px（18–40 共 23 档）。
- asar `extractFile` 要 Windows 反斜杠路径。
